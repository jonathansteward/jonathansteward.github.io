PJ-01Continuous AWS Compliance & Evidence Pipeline
flagship build

Built to close the gap between the enterprise ServiceNow IRM platform and the AWS environments it's supposed to govern. A detect loop runs daily at 8 AM CST: GitHub Actions pulls compliance status for seven AWS Config rules, writes evidence into ServiceNow against each mapped CIS v8 control over its REST Table API, and for every non-compliant control calls the Claude API for remediation guidance and runs a FAIR-informed Monte Carlo model (10,000 samples) to quantify exposure as a native ServiceNow risk record — one live finding carried $720K/year in exposure from a single IAM password-policy gap. The report goes out same-day as a PDF, delivered through a Slack bot and to the control owner's inbox. A parallel prevent gate converts every Terraform plan to JSON and evaluates it with Conftest against OPA Rego policies as a required branch-protection check, so non-compliant infrastructure is blocked at the pull request instead of remediated after it's already in production.

PJ-02Vendor Risk Automation Platform
TPRM

A Flask application that turns uploaded vendor security documentation or a completed questionnaire into a dollar-denominated FAIR risk assessment. Maps controls across six categories — governance, access controls, integration risk, AI risk, data security, and availability — using the FAIR-CAM model, runs a Monte Carlo simulation for P10/P50/P90 loss exposure, and ranks up to seven mitigation recommendations by simulated risk reduction before exporting the assessment to XLSX or PDF.
